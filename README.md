# Оно тебе надо
Ссылка на репозиторий: https://github.com/MiliDasha/ono-tebe-nado-ad
Одностраничный сайт аукциона «Оно тебе надо», выполненный как проектная работа по вёрстке.

## Просмотр

Откройте `index.html` в браузере — установка зависимостей и сборка не требуются.

## Структура

```text
MiliDasha-ono-tebe-nado-ad/
├── index.html
├── README.md
├── fonts/                  # локальные файлы Raleway и их подключение
├── images/                 # фоны, логотипы и иконки соцсетей
├── styles/                 # глобальные и локальные CSS-стили
└── .github/workflows/      # проверка проектной работы
```

## Использовано

- семантическая HTML-разметка;
- CSS Grid и Flexbox;
- локально подключённый шрифт Raleway;
- изображения и SVG-иконки из папки `images/`.
